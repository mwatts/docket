## Goal

Implement `docket sweep` command that finds bugs with linked changes that have been merged to trunk and marks them as done.

## Acceptance Criteria

- [x] Add `changes: Vec<String>` field to bug metadata for tracking jj change IDs
- [x] Add `docket link <bug-id> <change-id>` command to associate changes with bugs
- [x] Add `docket sweep` command that:
  - [x] Finds all in-progress bugs with linked changes
  - [x] Checks if all linked changes are ancestors of trunk (using `jj log`)
  - [x] Marks bugs as done if all changes are merged
  - [x] Reports what was closed

## Context

jj has a `trunk()` revset that finds the trunk branch. We can check if a change is merged with:
```
jj log -r "trunk() & <change-id>"
```

If this returns output, the change is in trunk.

The sweep command enables automatic cleanup - as work lands in trunk, bugs close themselves.
